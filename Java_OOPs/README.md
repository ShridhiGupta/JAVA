# Java OOPs

My notes and practice code for Object-Oriented Programming in Java — written
while learning the concepts, one program at a time.

## What's covered

- **Classes & Objects** — the building blocks
- **Constructors** — default, parameterized, copy
- **Inheritance** — extending classes, `super`, method overriding
- **Polymorphism** — compile-time (overloading) and runtime (overriding)
- **Encapsulation** — private fields, getters/setters
- **Abstraction** — abstract classes and interfaces

## How to run

You just need the JDK (17+ recommended). Compile and run any file:

```bash
javac FileName.java
java FileName
```
