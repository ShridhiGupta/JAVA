# Java

My personal Java playground — a collection of programs I've written while
learning the language and practicing DSA.

## What's inside

- **Basics** — syntax, loops, arrays, strings, OOP concepts
- **DSA practice** — sorting, searching, recursion, linked lists, stacks, queues, trees
- **Problem solving** — exercises and coding-challenge solutions

## How to run

You just need the JDK (17+ recommended). Compile and run any file:

```bash
javac FileName.java
java FileName
```

## Why this repo exists

Mostly for practice and revision. Things here aren't polished — they're
learning notes in code form. If you spot a better way to do something,
feel free to open an issue or PR.
